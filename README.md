Superstore Sales Dashboard | Power BI

Project Overview

This project presents an interactive Sales Dashboard built using the Superstore dataset. The goal was to transform raw sales data into meaningful business insights through data cleaning, analysis, and visualization.

The dataset was cleaned and processed using Excel and Python before being visualized in Power BI. The dashboard enables users to explore sales performance, profitability, customer segments, product categories, and regional trends.

---

Objectives

- Analyze overall sales and profit performance.
- Identify top-performing categories and segments.
- Track sales trends over time.
- Compare regional performance.
- Create an interactive dashboard for business decision-making.

---

Tools & Technologies

- Power BI
- Python (Pandas, NumPy)
- Microsoft Excel
- GitHub

---

Data Preparation

The dataset underwent several preprocessing steps before visualization:

- Removed duplicate records
- Handled missing values
- Corrected data formats
- Processed date fields for trend analysis
- Performed data validation and quality checks

Python and Excel were used to ensure the dataset was clean and ready for analysis.

Key Insights

- Consumer Segment generated the highest sales volume.
- Technology category contributed significantly to overall profit.
- Sales performance varied across regions, highlighting potential growth opportunities.
- Monthly sales trends revealed seasonal fluctuations in business performance.
